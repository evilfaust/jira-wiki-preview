# Jira Wiki Markup — Editor & Preview

Расширение VS Code для написания описаний и комментариев Jira: подсветка синтаксиса
Jira Wiki Markup и живое превью сбоку — так же, как это работает для Markdown.

[English README](README.md)

![Редактор и живое превью рядом](media/screenshot.png)

## Возможности

- **Превью в реальном времени** (`Cmd+Shift+V` / `Ctrl+Shift+V`) — панель сбоку, оформленная под Jira,
  со светлой и тёмной темой.
- **Синхронный скролл** в обе стороны и переход к строке по двойному клику в превью.
- **Подсветка синтаксиса** — и в редакторе, и в превью, включая содержимое блоков
  `{code:java}`, `{code:sql}`, `{code:json}` и ещё ~45 языков (highlight.js).
  Без указания языка (`{code}` и `{noformat}`) код показывается как есть.
- **Горячие клавиши форматирования**: `Cmd+B` — жирный, `Cmd+I` — курсив,
  `Cmd+Shift+M` — моноширинный, `Cmd+Alt+K` — ссылка. Повторное нажатие снимает форматирование.
- **Сниппеты**: `h1`, `code`, `table`, `panel`, `info`, `note`, `tip`, `warning`, `link`, `status` и другие.
- **Черновик в один клик**: команда `Jira: Новый Jira-документ (черновик)` открывает
  пустой файл с превью — удобно писать длинный комментарий и потом скопировать в Jira.
- **Копирование исходника**: `Jira: Скопировать исходник в буфер обмена` (копирует выделение или весь файл).
- **Оглавление**: макрос `{toc}` собирает заголовки документа со ссылками на них.
- **Проверка орфографии** русского и английского, знающая разметку: блоки кода,
  моноширинный текст, ссылки, имена макросов и ключи задач пропускаются — проверяется
  только проза. Быстрые исправления предлагают замену и добавление слова в словарь.

## Поддерживаемый синтаксис

Всё перечисленное подсвечивается в редакторе и отрисовывается в превью.

### Заголовки и абзацы

| Разметка | Что получается |
| --- | --- |
| `h1.` … `h6.` | Заголовки, у каждого свой якорь |
| Пустая строка | Новый абзац |
| Одиночный перенос | Перенос строки внутри абзаца |
| `\\` | Принудительный перенос строки |
| `----` (4 и больше) | Горизонтальная линия |
| `---` | Длинное тире — |
| `--` | Короткое тире – |
| `\*` | Экранирует следующий символ, чтобы он не считался разметкой |

### Начертание текста

| Разметка | Что получается |
| --- | --- |
| `*жирный*` | **жирный** |
| `_курсив_` | *курсив* |
| `-зачёркнутый-` | ~~зачёркнутый~~ |
| `+подчёркнутый+` | подчёркнутый |
| `^верхний^` | верхний индекс, как в `x^2^` |
| `~нижний~` | нижний индекс, как в `H~2~O` |
| `??цитата??` | цитата |
| `{{моноширинный}}` | `моноширинный` |
| `{color:red}текст{color}` | Цветной текст; принимает и `#RRGGBB` |
| `{status:colour=Green\|title=Готово}` | Цветной бейдж статуса |

### Списки

| Разметка | Что получается |
| --- | --- |
| `* пункт` | Маркированный список |
| `# пункт` | Нумерованный список |
| `- пункт` | Список с тире |
| `**`, `***`, … | Уровень вложенности равен числу маркеров |
| `*#`, `#*` | Смешанная вложенность: тип списка задаёт последний маркер |

Таблица или абзац между пунктами завершают список — так же ведёт себя Jira. Уровень
по-прежнему определяется маркерами, поэтому `**` после таблицы остаётся вторым уровнем.

### Таблицы

| Разметка | Что получается |
| --- | --- |
| `\|\|заголовок\|\|заголовок\|\|` | Строка заголовков |
| `\|ячейка\|ячейка\|` | Обычная строка |

Символ `\|` внутри `[…]` и `{…}` ячейку не разрывает, поэтому в ячейках работают ссылки
и макросы с параметрами.

### Блоки

| Разметка | Что получается |
| --- | --- |
| `{code}` … `{code}` | Блок кода |
| `{code:java}` … `{code}` | Блок кода с подсветкой языка |
| `{code:java\|title=Foo.java}` | Блок кода с заголовком |
| `{noformat}` … `{noformat}` | Текст без какого-либо форматирования |
| `{quote}` … `{quote}` | Блочная цитата |
| `bq. текст` | Цитата в одну строку |
| `{panel:title=…}` … `{panel}` | Панель; принимает `borderStyle`, `borderColor`, `borderWidth`, `bgColor`, `titleBGColor` |
| `{info}`, `{note}`, `{tip}`, `{warning}` | Цветные блоки-сообщения, каждый принимает `title=` |
| `{toc}` | Оглавление; принимает `minLevel`, `maxLevel`, `type=flat` |
| `{anchor:имя}` | Якорь для ссылок внутри документа |

`{code}` и `{noformat}` работают и внутри строки — чаще всего в ячейке таблицы, как в
`| {code:java}$code = "sbp";{code} |`.

### Ссылки и картинки

| Разметка | Что получается |
| --- | --- |
| `[https://example.com]` | Ссылка с адресом в тексте |
| `[текст\|https://example.com]` | Ссылка с подписью |
| `[текст\|https://example.com\|подсказка]` | Ссылка с всплывающей подсказкой |
| `[~username]` | Упоминание пользователя |
| `[^документ.pdf]` | Вложение |
| `[#якорь]` | Ссылка на якорь в документе |
| `https://example.com` | Голый адрес сам становится ссылкой |
| `ABC-123` | Ключ задачи становится ссылкой, если задан `jira.baseUrl` |
| `!картинка.png!` | Изображение |
| `!картинка.png\|thumbnail!` | Уменьшенное изображение |
| `!картинка.png\|width=300, align=right!` | Ещё принимает `height`, `border`, `vspace`, `hspace`, `alt`, `title` |

Относительные пути к картинкам ищутся рядом с открытым файлом.

### Эмотиконы

Рисуются классическими иконками Atlassian, а не системными эмодзи — чтобы превью
совпадало с тем, что показывает Jira.

| Разметка | Иконка | Разметка | Иконка |
| --- | --- | --- | --- |
| `(+)` | зелёный круг с плюсом | `(y)` | палец вверх |
| `(-)` | красный квадрат с минусом | `(n)` | палец вниз |
| `(!)` | янтарный треугольник-предупреждение | `(on)` | зажжённая лампочка |
| `(/)` | зелёная галочка | `(off)` | погашенная лампочка |
| `(x)` | красный крестик | `(*)`, `(*y)` | жёлтая звезда |
| `(i)` | синий значок информации | `(*r)` | красная звезда |
| `(?)` | синий вопросительный знак | `(*g)` | зелёная звезда |
| `(flag)` | красный флажок | `(*b)` | синяя звезда |
| `(flagoff)` | серый флажок | | |
| `:)` | улыбка | `:(` | грусть |
| `:D` | широкая улыбка | `;)` | подмигивание |
| `:P` | язык | | |

Также понимаются написания `:-)`, `:-(`, `;-)` и заглавные `(Y)`, `(N)`, `(I)`, `(X)`.

## Настройки

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `jira.preview.theme` | `jira` | Оформление превью: `jira` или `editor` (цвета темы VS Code) |
| `jira.preview.fontSize` | `14` | Размер шрифта в превью |
| `jira.preview.fontFamily` | системный | Шрифт текста в превью |
| `jira.preview.maxWidth` | `0` | Максимальная ширина колонки текста, px (`0` — без ограничения) |
| `jira.preview.scrollPreviewWithEditor` | `true` | Скролл превью вслед за редактором |
| `jira.preview.scrollEditorWithPreview` | `true` | Скролл редактора вслед за превью |
| `jira.preview.doubleClickToSwitchToEditor` | `true` | Двойной клик в превью → переход на строку |
| `jira.preview.highlightCode` | `true` | Подсветка синтаксиса внутри `{code:язык}` |
| `jira.baseUrl` | `""` | Базовый URL Jira: включает ссылки на задачи `ABC-123` и профили `[~user]` |
| `jira.spell.enabled` | `true` | Проверять орфографию |
| `jira.spell.languages` | `["ru","en"]` | Языки проверки; язык слова определяется по алфавиту |
| `jira.spell.userWords` | `[]` | Слова, которые всегда считать правильными |
| `jira.spell.minWordLength` | `3` | Не проверять слова короче этой длины |
| `jira.spell.ignoreAllCaps` | `true` | Не проверять слова капсом — обычно это аббревиатуры |

### Про проверку орфографии

Словари hunspell читаются через [nspell](https://github.com/wooorm/nspell) и живут
в **отдельном процессе**, а не в процессе расширения: русскому словарю нужно около
250 МБ памяти и примерно секунда на сборку. Процесс поднимается при первой проверке
и закрывается после пяти минут простоя, поэтому платите за него только пока реально
пишете текст. Подсказки считаются лениво — в момент открытия меню быстрых исправлений.

Жаргон вроде «деплой» словарь не знает — такие слова добавляются одним кликом
через быстрое исправление «Добавить в словарь».

## Как открыть файл как Jira-разметку

Расширение включается для файлов `.jira`, `.jira.txt`, `.jirawiki`. Для любого другого
файла язык можно переключить вручную: `Cmd+Shift+P` → `Change Language Mode` → `Jira Wiki Markup`.

## Разработка

```bash
npm install
npm run compile      # сборка в dist/
npm run watch        # пересборка при изменениях
npm test             # тесты парсера
npm run typecheck    # проверка типов
npm run grammar      # пересобрать TextMate-грамматику
npm run icon         # пересобрать иконку расширения
npm run vsix         # сборка .vsix
npm run release:github # тег, сборка и релиз на GitHub
npm run release:github -- --dry-run     # весь путь, кроме публикации
npm run release:github -- --checks-only # только проверки, без сборки
```

Отладка: `F5` в VS Code запускает Extension Development Host с открытым `samples/demo.jira`.

Грамматика `syntaxes/jira.tmLanguage.json` генерируется из `scripts/gen-grammar.js`
(там же список языков, подсвечиваемых внутри `{code:…}` в редакторе); парсер живёт
в `src/parser/` и не зависит ни от API VS Code, ни от highlight.js — подсветка
подключается к нему через опцию `highlightCode`, поэтому парсер покрыт обычными
юнит-тестами (`test/parser.test.ts`, `test/highlight.test.ts`).

Набор языков для подсветки в превью — `highlight.js/lib/common` плюс несколько
дополнительных в `src/highlight.ts`; там же живут алиасы вроде `gradle` → `groovy`.
